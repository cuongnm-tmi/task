## OVERVIEW

ICON MODE Store has been rebuilt around Google Filament. The active real-time
runtime is now the CMake/C++ project in `src/`, and Blender generates the
reference-style store GLB consumed by Filament. The former raw OpenGL
Visual Studio path is no longer the product runtime.

## CONVENTIONS

- Build system is CMake. Do not revive the old `.slnx` / `.vcxproj` path.
- C++ standard is C++20.
- Runtime model is `assets/models/icon_mode_store.glb`, generated by Blender.
- Filament is external and supplied through `FILAMENT_ROOT`; do not vendor it
  into this repository.
- `vcpkg.json` only lists SDL2 for window/input support.

## COMMANDS

```bat
REM Generate runtime GLB
blender.exe --background --python blender\icon_mode_scene.py -- --skip-render --glb-output assets\models\icon_mode_store.glb

REM Render still preview and export GLB
blender\render_eevee.bat

REM Configure and build viewer
cmake -G Ninja -B build -S . -DCMAKE_BUILD_TYPE=Release -DFILAMENT_ROOT=C:\dev\filament\out\cmake-release
cmake --build build
build\icon_mode_store.exe --model assets\models\icon_mode_store.glb
```

## ANTI-PATTERNS

- Do not edit raw GLSL/PBR/shadow-map code as the primary path.
- Do not add GLFW, GLAD, Assimp, or GLM back into the runtime.
- Do not use `image/` as tracked app assets; it is reference input only.
- Do not treat generated `assets/models/*.glb` as hand-authored source.
