# ICON MODE Assets

This folder is the source of truth for the Filament stack.

```text
assets/
  source/      Original OBJ/JPG inputs used by Blender.
  models/      Generated GLB files for the C++ Filament viewer.
  textures/    Optional KTX2 textures generated by Filament tools.
  ibl/         Optional cmgen output for future reflection probes.
```

Generate the main runtime model:

```bat
blender.exe --background --python blender\icon_mode_scene.py -- --skip-render --glb-output assets\models\icon_mode_store.glb
```

Render a still preview with EEVEE Next:

```bat
blender.exe --background --python blender\icon_mode_scene.py -- --output renders\icon_mode_eevee.png --samples 64
```
